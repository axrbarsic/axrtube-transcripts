# Изменения

## 1.0.0, 16 ноября 2026

Первая версия отдельного приложения.

- Полная стенограмма ролика: «Копировать всё», вариант с таймкодами, поиск по тексту, выбор языка, ссылка на момент ролика.
- Субтитры в первую очередь через мобильные клиенты YouTube, запасной источник: панель «Показать расшифровку».
- Обсуждение через YouTube Data API v3: лента «Популярные / Новые», ветки ответов, публикация комментариев и ответов от имени пользователя.
- Вход через Google с PKCE и зашифрованными cookies, разрешение на комментарии `youtube.force-ssl`.
- Поиск роликов, подсказки, недавние ролики на устройстве.
- PWA: установка на экран «Домой», светлая и тёмная тема, `share_target` для Android.
